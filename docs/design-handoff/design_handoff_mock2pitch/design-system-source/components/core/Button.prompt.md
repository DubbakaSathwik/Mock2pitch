Pill button for all actions; primary (Imperial Blue) for the main step on a screen, accent (Bright Marine) for secondary emphasis, record (red) only for starting/stopping a recording.
```jsx
<Button iconLeft="upload">Upload slides</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="record" iconLeft="mic">Start practice</Button>
```
Variants: primary · accent · secondary · ghost · record · inverse (on navy). Sizes sm 36 / md 44 / lg 52. Hover darkens, press scales to .97.
